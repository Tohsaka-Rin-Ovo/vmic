# vmic

vmic 是一个 iOS 通话音频桥接与本地音频管理应用。它负责导入、整理并播放本地音频，并在系统与当前通话 App 支持时，把播放内容加入通话输入。

它不是系统级虚拟麦克风，也不会绕过 iOS 的音频权限限制。实际效果取决于 iOS 的“通话中添加音频”能力，以及当前通话是否暴露 Apple 麦克风注入通道。

vmic 还提供一个底部播放 dock。它会在首页、音频列表和设置页保持可见，调试页默认隐藏，可在设置中切换。

## 功能

- 导入本地音频，读取标题、作者、时长和内嵌封面。
- 管理音频列表，支持播放、暂停、拖拽排序、重命名和从 App 内移除。
- 在首页查看系统权限、注入通道和注入开关状态。
- 调整输入音量，并在底部播放 dock 中拖拽调整播放进度。
- 可选后台悬浮窗：播放中切到后台时尝试用系统 Picture in Picture 展示当前音频封面，回到前台后自动收起。
- 提供通道调试页，用于刷新状态、复制诊断信息和查看当前 AVAudioSession 信息。
- 调试页默认不显示底部 dock，可在设置中开启。
- 默认中文界面，可在设置中切换语言与主题。

## 运行要求

- 麦克风注入功能需要 iOS/iPadOS 18.2 或更高版本。
- 项目最低部署版本为 iOS 18.2，低版本设备会进入不支持提示页。
- 建议使用 Xcode 16.2 或更高版本。
- 必须使用真机测试，模拟器无法验证电话、FaceTime 或 VoIP 通话注入。

## 首次运行

1. 在 macOS 上打开 `vmic.xcodeproj`。
2. 将 Bundle Identifier 从 `com.example.vmic` 改为自己的开发者标识。
3. 在 Xcode 中选择开发团队，并使用真机运行。
4. 打开系统设置中的 `辅助功能 > 音频与视觉 > 通话中添加音频`。
5. 开启系统开关，并允许 vmic 添加音频到通话。
6. 回到 vmic，导入音频并进入电话或 FaceTime 通话测试。
7. 在首页确认“通道”可用后开启注入，再播放音频。

## 兼容性

iOS 顶部显示“通话中”不代表注入通道一定可用。vmic 会通过系统能力查询当前通道状态：

- 如果通道显示可用，可以继续测试对方是否能听到播放的音频。
- 如果通道显示不可用，说明当前通话没有暴露 Apple 麦克风注入通道，软件侧无法强行注入。

KOOK、微信电话等 VoIP App 需要按具体版本和设备实测。

## 调试

首页和设置页都提供调试入口。调试页会显示当前权限、通道状态、输入输出端口、Category、Mode、采样率和最近一次通道事件。

如需排查兼容性，可以在进入目标 App 通话后打开 vmic 调试页，刷新状态并复制诊断信息。
